# 런북: Figma

프로젝트의 디자인 시스템과 코드로 Figma 파일을 만드는 순서입니다. Figma를 손으로 그리지 않습니다. 디자인은 코드에서 끝내고 Figma에는 결과를 옮기세요. 기준 버전은 **2.1.0**입니다.

색·여백·모서리·글자 크기는 모두 SLDS hook과 같은 이름의 변수(`color/accent/1`, `spacing/4` 등)에 묶여 있습니다. 개발자가 Figma에서 값을 보면 코드에 쓸 hook 이름(`var(--slds-g-…)`)이 함께 나옵니다.

## 1. 준비 (사람마다 한 번)

- **Figma 데스크톱 앱**을 설치하세요. 웹에서는 개발 플러그인이 실행되지 않습니다. 무료(Starter) 플랜으로 됩니다
- 글꼴 **Pretendard**를 설치하면 문서·표지가 Pretendard로 나옵니다. 없으면 Noto Sans KR, 그것도 없으면 Inter로 나옵니다
- Figma에서 **Drafts에 빈 새 파일**을 만드세요. 운영 중인 파일에서 돌리지 마세요(무료 플랜은 파일당 3페이지이고 플러그인이 3페이지를 다 씁니다)

## 2. 초기 세팅 (Figma 파일마다 한 번)

```bash
pnpm milvus figma --name 고객사이름
```

`.milvus/figma/`에 플러그인과 `figma-data.json`이 생깁니다. 변수 값은 프로젝트 브랜드(BrandingSet의 `BRAND_COLOR`, `milvusBrand.css`)에서 옵니다.

1. Figma 메뉴 **플러그인 → 개발 → 매니페스트에서 플러그인 가져오기…** → `.milvus/figma/manifest.json` (처음 한 번)
2. **플러그인 → 개발 → Milvus Design System → 디자인 시스템 생성 (figma-data.json)** → `.milvus/figma/figma-data.json`
3. 창에 `완료: 컴포넌트 ○개 …`가 나오면 끝입니다. 몇 분 걸립니다

- `.milvus` 폴더가 파일 선택 창에 안 보이면 macOS는 `Cmd + Shift + .`을 누르세요
- 브랜드를 바꾼 뒤에는 같은 순서로 다시 실행하세요. 새로 만들지 않고 갱신합니다
- 패키지를 새 버전으로 올렸으면 이 단계부터 다시 실행하세요. 3단계의 변형 이름이 새 버전 기준이라 맞지 않을 수 있습니다

## 3. 컴포넌트·페이지 옮기기

2단계를 마친 Figma 파일에 **프로젝트에서 만든 LWC와 FlexiPage만** 옮깁니다. 코드를 읽어 옮기므로 Storybook·Chrome이 필요 없습니다.

```bash
pnpm milvus figma
```

`1) 초기 세팅 2) component 3) page`를 묻습니다. 고른 뒤 이름을 쉼표로 넣으세요. 한 줄로도 됩니다.

```bash
pnpm milvus figma --component accountSummary,modal_accountEdit
```

```bash
pnpm milvus figma --page Account_Record_Page
```

`.milvus/figma/figma-update.json`이 생기면 **플러그인 → 개발 → Milvus Design System → 선택한 것만 반영 (figma-update.json)** 에서 고르세요. 고른 것만 지우고 다시 그리고 나머지는 그대로 둡니다. 페이지에 프로젝트 LWC가 들어가면 그 LWC를 **먼저** component로 옮기세요. 안 옮긴 LWC는 이름 붙은 자리 표시로 그려집니다.

코드는 이렇게 옮겨집니다.

- 레코드 상세·관련 목록·하이라이트 패널 같은 표준 컴포넌트는 이름 붙은 자리 표시 상자로 그립니다
- 탭은 활성 탭의 내용만 그립니다
- FlexiPage가 프로젝트에 없고 org에만 있으면 먼저 받으세요: `sf project retrieve start -m FlexiPage:<이름>`

## 4. 외부 제출용 PDF

각 페이지에서 Figma 메뉴 **파일 → 프레임을 PDF로 내보내기**를 쓰세요. 표지와 컴포넌트 문서 프레임이 PDF가 됩니다.

## 다른 Figma 파일의 값 가져오기

고객사 Figma의 색·글자·간격을 브랜드에 쓰고 싶으면, 그 파일에서 **플러그인 → 개발 → Milvus Design System → 이 파일의 변수·스타일 내보내기**로 JSON을 받으세요. 컴포넌트 모양도 필요하면 실행 전에 컴포넌트 세트를 선택하세요. 받은 JSON을 Claude Code에 주고 "브랜드 요청 반영해줘"라고 하면 **런북 / Storybook**의 2단계처럼 반영합니다.
